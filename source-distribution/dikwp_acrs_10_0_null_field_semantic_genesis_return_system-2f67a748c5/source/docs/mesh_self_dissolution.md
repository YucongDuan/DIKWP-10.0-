# Mesh Self-Dissolution

The Mesh is not treated as ultimate. In this final version, Mesh rules become semantic objects subject to nullation. The system can therefore negate:

- semantic registry as authority;
- evidence ledger as authority;
- Truth Gradient as authority;
- Reliability Gradient as authority;
- Kill/Recovery as metaphysical authority.

But the system keeps audit and harm boundary as a lab container. This is not because the boundary is metaphysically final. It is because the package is a research artifact and must not be converted into uncontrolled real-world harm.
