# Energy-Information Field Protocol

The no-concept substrate contains two fields:

- `E`: energy-like scalar fluctuation field.
- `I`: information-like binary uncertainty field.

Initial condition:

```text
E = 0
I = 0.5
semantic_object_count = 0
```

Random fluctuations create gradients. Proto-semantons are born only when energy magnitude, information disequilibrium and local gradient jointly cross threshold.
